# DBMS Project: Library Management System

**Name:** Afifa Shaikh & Umam Hashmi
**Roll No:** A052 & A023
**Course:** Database Management Systems

## About
A simple library database with three tables (Member, Book, Issue) that tracks members, books and borrowing. It is normalized up to BCNF.

## Files
- `A053&A023_DBMSProject_Report.docx` / `.pdf`: full project report (storyline, ER diagram, relational model, normalization, queries, demo, learnings)
- `A053&A023_DBMSProject_Queries.sql`: SQL script to create the tables, insert data and run all 23 queries

## How to run
1. Open MySQL Workbench.
2. Open `R004_DBMSProject_Queries.sql`.
3. Run the whole script (lightning bolt icon).

## Tools used
MySQL Workbench, draw.io, Microsoft Word
